# 张忻霖题一备赛包：避障游戏问题

本文件夹用于准备“第五届上海市中学数学学术展评活动”的长期题一。目标不是把题目包装成成人式的高深证明，而是帮助六年级学生真正理解问题、能讲出自己的方法、能回答评委追问。

## 使用顺序

1. 成人先读 `00-正式题面与结论边界.md`，并逐字对照根目录 `长期题1.png`。
2. 学生读 `01-学生讲义.md` 和 `06-研究报告.md`，理解模型、证明与计算。
3. 用 `02-展示讲稿.md` 和网页按12分钟正式陈述节奏演练。
4. 用 `03-互动攻防与16分钟答辩.md`、`04-训练计划.md` 做追问和压力测试。
5. `08-第二问一般n层研究.md`、`09-第三问旋转障碍物与100卡优化.md` 覆盖第二、三问。
6. `10-活动流程与提交清单.md` 管理7月25日提交与40分钟现场流程。
7. `11-完整PDF内容母稿结构.md` 是最终“研究方案+研究结果”合并PDF的内容骨架。
8. 最终送审文件为 `output/pdf/长期题一-避障游戏-研究方案与研究结果-最终版.pdf`。

## 当前版本的定位

- 主攻长期题一。
- 准备周期按 2-4 周设计。
- 路线是“图形直观 + 口头表达 + 简单计算”。
- 已严格证明 0 张卡不可能，并计算验证 9 张可行，所以当前严格范围为 `1≤M≤9`。
- “9 张最优”仍是实验猜想；不得写成已证明结论。
- 正式题面已在工作区；所有结论必须以 `长期题1.png` 为最高依据。
- 总目标是初赛突破：真实过程、可验证成果、清楚表达和诚实边界优先于虚构完整证明。
- 四名现场学生（六、六、七、八年级）全部参与陈述、互动和答辩。
- GitHub待数学内容稳定后由主任务统一处理，本目录不自行配置远程仓库。

## 最核心的一句话

机器人半径 1 米、障碍物半径 8 米，可以转化为：把机器人看成一个点，把每个障碍物变成半径 9 米的安全禁区；于是题目变成点在正三角形网格中的避障路线问题。
