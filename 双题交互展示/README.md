# 双题交互研究展示

双击 `index.html` 即可离线运行，无需安装、联网或启动服务器。

## 现场建议流程

1. 用题一“一般 n 层”说明点化、安全圆与显式构造。
2. 先切换“旋转机制”观察60秒刚性旋转，再切换“100卡方案”观察真实的高速短时过程。
3. 用键盘右方向键进入题二。
4. 按“下一步”从九点结构、一个三角形、colex 极值构造讲到结果区间。

建议只在两处播放动画：题一点化到安全圆约30秒，100卡方案约45秒；题二以分步点击为主，避免连续动画分散评委对证明逻辑的注意。

## 快捷键

- 左/右方向键：切换题目。
- 空格：题一播放/暂停；题二进入下一步。
- R：复位当前题目。
- 页面右上角：进入全屏展示。

## 结论边界

- 题一一般 n 层展示的是严格可行构造与上界 `M(n)≤24n`，不是精确最优值。
- 题一 100 卡方案展示的是可复算下界 `D≥94.5106m`（19 张加速卡 + 81 张转向卡），不是全局最大值。画面重点绘制前5层，但验证算法检查的是无限网格。
- 题二高端闭合区间标为严格结果；中低密度阶梯只标为程序验证候选。

正式现场前请同时准备关键页面截图或录屏，以防投影机或浏览器临时故障。

## 现场验收清单

- 使用实际比赛电脑和投影仪测试1920×1080与1366×768两种分辨率。
- 确认浏览器缩放为100%，系统显示缩放不会遮挡右侧指标。
- 完整走一遍鼠标操作，再仅用键盘走一遍。
- 关闭网络后重新打开，确认仍能正常运行。
- 四名学生每人负责一段操作，并安排一人专门处理复位或切题。
- 截取“9米安全圆”“100卡终点”“九点结构”“严格区间”四张备用图片。
