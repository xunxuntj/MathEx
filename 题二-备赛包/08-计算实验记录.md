# 计算实验记录

## 目的

对 \(n=9,10\) 和每个边数 \(m\)，寻找包含固定
\(F=\{01,02,03,04,56,78\}\) 的图，使三角形数尽量大。

## 方法与复现

- `tools/search_envelope.py`：固定随机种子 20260720，多次随机初始化并做单边交换；
- `search-n9.json`、`search-n10.json`：每行保存边数、找到的三角形数、通用上界、是否闭合以及完整边集；
- 三角形通过枚举全部 \(\binom n3\) 个三元组独立复算；
- `tools/compute_exact.py`：预备的 0-1 整数规划模型。当前环境未能下载 SciPy，故未把它的结果写入结论。

复现命令：

```powershell
python tools/search_envelope.py 9 --out search-n9.json --restarts 150
python tools/search_envelope.py 10 --out search-n10.json --restarts 60
```

## 闭环判据

若“找到的三角形数 = 固定边数通用上界 \(T^*(m)\)”，则该行精确。反之，该行只是构造下界；反演得到的 \(E(n,k)\) 只是上界，除非另有人工证明。

## 结果摘要

- 两个规模在 \(m=29\) 以及之后的大部分行达到通用上界；
- \(n=9\) 的 \(m=30\) 到 36 可认证对应的 E 区间；
- \(n=10\) 的 \(m=38\) 到 45 可认证 \(k=85\) 到 120；
- 中低密度行仍有通用上界缺口，不能声称穷尽。

2. 改用无外部依赖的可复现搜索，并以通用上界做认证门槛；

4. 即使求解器给出数值，仍需人工解释为什么固定一个 F 不损失一般性。
