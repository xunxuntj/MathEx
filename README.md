## 长期题一：避障游戏

核心转化是把半径1米的机器人视为点，同时把半径8米的障碍物扩大为半径9米的安全圆。

当前主要结果：

- 对一般前 `n` 层给出显式安全构造与严格上界 `M(n) ≤ 24n`；
- 构造已验证至20层，交互页面支持1–12层展示；
- 第三问保留19张加速卡加81张转向卡的94.5106米基线；
- 当前更强候选使用47张转向卡加53张加速卡，速度约136.85万米/秒；
- 保守过程约0.00012962秒，障碍物旋转约0.00078°；
- 保守可达174.5136米，安全余量约0.01458米，并已独立复核。

94.5106米是可复算可行下界，不是未经证明的全局最大值。
174.5136米同样是采样路径的可复算候选，不宣称100卡全局最优。

## 长期题二：图论极值

把题目转化为在简单图中包含 `F = K₁,₄ ∪ 2K₂`，并在至少含 `k` 个三角形时最小化边数。

当前主要结果：

- 严格证明 `E(n,1)=7`；
- 给出固定边数下三角形数量的通用上界；
- 给出一般 `n`、最低度约束和连通限制下的上下界构造；
- 对 `n=9,10` 给出可复算候选阶梯，并认证若干高密度精确区间；
- 严格证明连通限制下 `E_c(n,1)=n`。

中低密度候选没有被包装成已完成的穷尽证明。
